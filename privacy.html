Privacy Policy

Last updated: 2026-09-29

This application is a personal-use integration between a privately run Hermes AI assistant and a single individual's Google Calendar account. It is used solely by its owner for personal scheduling, reminders, and calendar review.

Data accessed

The application requests read/write access to Google Calendar data (events, calendar list) for the owner's own account only.

Data sharing

No calendar data is shared with, sold to, or processed by any third party. Data is used exclusively to generate personal summaries and reminders for the account owner.

Data storage

OAuth credentials and any cached calendar data are stored locally on the owner's own private server and are not transmitted elsewhere.

Contact

This is a personal, non-commercial project with a single user. There is no public support channel.
